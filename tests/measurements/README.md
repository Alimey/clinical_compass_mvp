# Технические замеры

Инструменты для измерения отклика API и интерфейса, нагрузки, доставки SOS и восстановления данных. Каждый прогон использует временную базу и сохраняет результаты отдельно.

| Файл | Назначение |
| --- | --- |
| `run_local.py` | Общий запуск замеров и серверных тестов, HTML-отчёт |
| `run_benchmarks.py` | Нагрузка, API, рост данных и восстановление после остановки процесса |
| `run_ui_metrics.py` | Открытие экранов, сохранение дневника и уведомления SOS |
| `run_validation.py` | Полный набор серверных и браузерных проверок для Linux |
| `runtime.py` | Выбор и запуск тестового сервера: Waitress или Gunicorn |
| `build_report.py` | PDF и графики исходного стендового сеанса |
| `requirements-local.txt` | Дополнительные зависимости для локальных тестов |

Для запуска на Windows из корня проекта предусмотрен `run-local-tests.cmd`. Результаты сохраняются в `test-results/`; они относятся к компьютеру и конфигурации конкретного прогона.
