# Эксперименты с дизайном

Ветка `design/experiments` создана от `main` (`39ffb44`). Изменения в ней не попадают в `main` автоматически.

В приветственном блоке пациента появилось дерево: ветви плавно покачиваются, цветы меняют размер, лепестки опадают. Используется то же дерево заботы, что и в разделе «Моё дерево». Сохранены голубая палитра, розовые цветы и адаптация под телефон, планшет и компьютер. SVG и анимация находятся в приложении, сторонние сервисы не нужны.

Кнопка «Пауза» останавливает движение; «Продолжить» запускает его снова. Выбор сохраняется при переходах между разделами до перезагрузки страницы. Если в операционной системе включено уменьшение движения, дерево статично, кнопка скрыта.

Снимки: [телефон](screenshots/tree-home-mobile.png) · [компьютер](screenshots/tree-home-desktop.png).

Чтобы опробовать ветку в уже скачанном проекте:

```sh
git fetch origin
git switch design/experiments
```

Запустите сервер по инструкции в README, откройте приложение и войдите как Александра. При старом оформлении обновите страницу при доступном сервере: версия кэша оболочки — `compass-shell-v6`.

## Что доступно без связи с сервером

После первого открытия с доступным сервером браузер сохраняет оболочку PWA. Для просмотра данных пациенту нужно заранее открыть «Ещё» → «Назначения и записи без интернета», задать PIN из шести цифр и нажать «Сохранить офлайн-копию».

В копии доступны только чтение плана и назначений, расписание консультаций, история посещений и текст результатов анализов. На экране указана дата сохранения. Это снимок данных; изменения на сервере появляются после обновления копии. Выход из аккаунта удаляет копию. Кабинеты врача и близкого такой копии не сохраняют.

Чат, новые записи дневника, ответы на опросы, отметки приёма, запись на консультацию, SOS, изменение согласий и сохранение прогресса требуют сервера. Очереди отправки изменений после восстановления сети нет. Дерево и его кнопка паузы продолжают работать на уже открытом экране. Полную навигацию по разделам офлайн приложение пока не поддерживает.

Если сервер запущен на вашем компьютере, браузер на этом компьютере может пользоваться основными функциями без внешнего интернета. Телефону нужен доступ к этому серверу по локальной сети или интернету. Внешние ИИ API, Telegram и доставка push требуют внешнего подключения.

Проверки: `python tests/browser_responsive.py` (анимация, пауза без сети, уменьшение движения, восемь размеров экрана) и `python tests/browser_workflows.py` (в том числе сохранение зашифрованной копии, неверный PIN, открытие без сети и удаление при выходе).
