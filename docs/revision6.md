# «Правки 6» — главный экран, уведомления и навигация

Изменения из DOCX внесены в ветку `design/experiments`. Цветовая палитра и компоновка для компьютера сохранены.

| Раздел | Что изменилось |
|---|---|
| Главная пациента | Дерево осталось здесь; кнопка «Моё дерево» удалена. На телефонах с тремя колонками последние две круглые кнопки расположены симметрично по центру. |
| Движение | Убрано повторное дерево. Календарь, упражнения и отметки активности сохранены. Цветы, добавленные на главной, продолжают сохраняться. |
| Личный отсчёт | Вместо графика на главной отображается счётчик из «Помощи». Начало, перезапуск и остановка используют те же сохранённые настройки; время обновляется каждую секунду. В «Помощи» счётчик тоже доступен. |
| Сезонная карточка | На главной появился небольшой блок о времени года. Осенью — «Световой день становится короче». Текст выбирается по текущему месяцу; внешняя новостная лента не требуется. |
| Вход | Цветущее дерево и пять поддерживающих фраз с кнопкой «Другая мысль». Начальная фраза меняется по дням. На телефоне блок находится над формой, на компьютере — справа. Личные цветы пользователя на экране входа не отображаются. |
| Уведомления | Ровные отдельные карточки. Нажатие сразу меняет фон, статус и число непрочитанных, оставляя список открытым. Переходов в другие разделы нет. При ошибке сохранения возвращается непрочитанный статус и появляется сообщение; повторное нажатие позволяет сохранить его. |
| Нижнее меню | На телефоне и планшете появились стрелки в обе стороны. Они прокручивают пункты меню и скрываются на соответствующем краю. Прокрутка пальцем сохранена. |
| Назад | Более заметная кнопка с обводкой. Возврат в уже открытый родительский раздел использует существующую историю, поэтому путь «Главное → Пациенты → Карточка → Все пациенты → Назад» заканчивается на главной. Поддерживаются и кнопки браузера «Назад» / «Вперёд». |

Фразы на входе написаны для приложения, без приписывания их другим авторам. Уведомления сохраняют отметку прочтения через прежний серверный API; задержавшийся ответ опроса сервера не возвращает только что прочитанную карточку в непрочитанные.

## Как проверить

1. Открыть приложение: над формой входа на телефоне видны дерево и фраза. Нажать «Другая мысль».
2. Войти как Александра. Проверить дерево, симметрию круглых кнопок, личный отсчёт и сезонную карточку. Запустить отсчёт, затем открыть «Помощь → Счётчик»: время начала то же.
3. Открыть «Движение»: дерева больше нет, календарь и упражнения доступны.
4. На телефоне нажать стрелку справа от нижнего меню: станут доступны остальные вкладки. Вернуться стрелкой слева или жестом.
5. В отдельных браузерах войти как врач и пациент. Отправить сообщение пациенту; в его уведомлениях нажать карточку. Она сразу станет прочитанной, список останется открыт, адрес страницы не изменится.
6. В кабинете врача пройти «Главное → Пациенты → Карточка → Все пациенты → Назад». Повторить с кнопками браузера.

## Проверки и обновление

`tests/browser_revision6.py` проверяет эти сценарии в Chromium, включая реальное серверное сохранение прочтения, задержанный ответ сервера, откат при ошибке, историю браузера и ширины 320–1440 px. Также проверены существующие сценарии в `browser_smoke.py`, `browser_responsive.py`, `browser_revisions.py`, `browser_revision2.py`, `browser_sections.py`, `browser_psicompas.py` и `browser_games.py`.

База данных и переменные окружения не менялись. Новый стиль включён в PWA-кеш `compass-shell-v14`; серверные данные уведомлений по-прежнему не кешируются оболочкой.

На Render открыть сервис с веткой `design/experiments`, выбрать **Manual Deploy → Deploy latest commit**, дождаться **Live**, затем обновить страницу приложения. Автоматический деплой сработает сам, если он включён для этой ветки.
