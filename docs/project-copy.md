# Тексты из «Проектика»

Обновление ветки `design/experiments` по документу от 24 октября 2026 года. Рабочий объём — тексты и демонстрационные примеры; отдельные функциональные предложения перечислены ниже.

| Раздел | Внесено |
|---|---|
| Письма пациента | 10 тем из документа; срок ответа 1–2 рабочих дня и указание на SOS / 112 для срочной помощи |
| Письма врача | 4 примера: два новых и два с ответами; фильтры «Новые», «Отвеченные», «Все» |
| Чат Александры | 4 сообщения о дневнике, сонливости и плане безопасности вместо единственной заглушки |
| Форум | 6 дополнительных тем от двух врачей; среди них вовлечение родственников; исправлены формы «сообщение / сообщения / сообщений» |
| Новости | 3 самостоятельных примера новостей компании с явной пометкой «Пример» |
| Карточка Александры | Отображаемый код МОО97-26; убраны повторяющиеся сведения о вымышленном источнике и учебном ограничении |
| Назначения | В примерах Александры и Михаила — «Авиандр 20 мг» и схема из предоставленного документа: 1 таблетка дважды в день за 30 минут до еды. Назначение показывается в терапии и таблетнице |
| Анализы Александры | Гемоглобин 128 г/л, СКФ 98 мл/мин, АЛТ 21 Ед/л вместо условных маркеров |
| Правила | Понятные формулировки причин сигналов и метки «Обязательно» / «Желательно» без технической версии в подписи предложения |
| Лицензируемые методики | MMPI и обе формы Бека: «Проводится на приёме по лицензии», без онлайн-вопросов. Онлайн-назначение и отправка ответов заблокированы сервером; старые результаты сохраняются |
| Контакты | Понятные названия разделов, удалён повтор МСПП, у 103 пояснение о вызове экстренной психиатрической помощи |
| Видео | Пять мест по 3 минуты для пациента и три для близкого; сами видеозаписи ещё не приложены |
| Общие подписи | Пометка «Демо-данные» в подвале, убрана подпись о синтетическом чате и техническая подпись быстрого входа |

Данные добавляются однократным обновлением базы. Оно заменяет только точно совпадающие исходные примеры; пользовательские письма и ответы не перезаписываются. Повторный запуск не дублирует письма и темы форума.

## Что требует отдельного согласования

- **Официальная инструкция Авиандра.** Дозировка выше перенесена из пользовательского документа как запись демонстрационного кейса. Противопоказания, взаимодействия, утверждения о сроках побочных эффектов и основания со ссылкой на раздел инструкции не проверены. Официальные сайты из этой среды вернули HTTP 403. Действующий демонстрационный калькулятор не переименован в проверенную систему назначения реального препарата; прежние внутренние варианты и ограничения не подменялись клиническими правилами.
- **Спорные телефоны.** Номера ПКБ № 1, «Без паники», кризисного центра для женщин и детей и телефона помощи женщинам не удалось сверить. Их кнопки набора временно скрыты; показана необходимость проверки, для известных официальных сайтов сохранены ссылки. Номера 112 и 103 доступны. Непроверенные альтернативы из документа не добавлены.
- **Функциональные задачи.** Шифрование базы, общий формат кодов для всех пациентов, 7 вкладок карты, календарь записи с переносом и PDF-заключениями, новые пациенты калькулятора, фармаконадзор, личные данные и новые сигналы близкого — отдельные изменения, не выполненные как простые замены текста. МОО97-26 — подпись карточки, а не шифрование данных.
- **Помощник.** Существующее подключение внешнего ИИ сохранено. Ответы по лекарству не заменены непроверенным справочником; работающий ИИ не имитируется.
- **Внешние материалы.** Ссылка на план безопасности из DeepSeek, видео и инструкция не приложены к этому документу. Переписка с участниками команды, презентация и постер не выполнялись.

Ключевые предупреждения о границах учебных форм и реальной работе подключений сохранены: одна пометка о демоданных не превращает сокращённые вопросы в полные шкалы и не подтверждает интеграции.

## Проверка и запуск

Серверные проверки охватывают повторный запуск обновления, сохранность пользовательских писем и запрет онлайн-прохождения лицензируемых методик. Браузерные сценарии проверяют темы и фильтры писем, заполненный форум, код Александры, назначение из документа и отсутствие лицензируемых методик в выборе онлайн-форм.

На Render: **Manual Deploy → Deploy latest commit**, дождаться **Live**, обновить страницу. Сбрасывать базу не нужно. Версия оболочки PWA — `compass-shell-v19`.
