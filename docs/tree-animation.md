# Анимация дерева при касании

На главной и в «Движении» каждый новый цветок получает случайный размер в небольшом диапазоне. Он раскрывается за 620 мс с лёгким пружинящим эффектом. Дерево покачивается с затуханием около секунды: максимальный дополнительный наклон — 2,5°. Обычная анимация ветра продолжается независимо.

Повторное касание начинает покачивание от текущего положения. Появившиеся цветки не создаются заново при сохранении на сервере, поэтому их раскрытие не обрывается и старые цветки не вспыхивают повторно.

Размеры сохраняются вместе с координатами и остаются прежними после перезагрузки. При запуске приложение автоматически добавляет поле размера к существующей таблице; старые цветки и другие данные сохраняются. Для старых цветков остаётся прежний размер.

В режиме уменьшения движения цветки появляются сразу, без раскрытия и дополнительного покачивания. Изменение этой системной настройки останавливает уже запущенные эффекты. Реакция на нажатие работает локально; сохранение цветков по-прежнему требует связи с сервером.

Проверки: 18 серверных тестов (`test_wellbeing.py`, `test_patient_revision2.py`) и два браузерных набора (`browser_revision2.py`, `browser_psicompas.py`). Проверены быстрые повторные касания, вариация и сохранение размеров, положение и анимация дерева, сохранение узлов при ответе сервера, режим уменьшения движения, обновление старой базы, PWA и прежние сценарии пациента.

На Render: ветка `design/experiments` → **Manual Deploy → Deploy latest commit** → дождаться **Live** → обновить страницу. Оболочка PWA — `compass-shell-v11`. Новые переменные окружения не нужны.
