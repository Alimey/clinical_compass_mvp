# Правки из документа «Текущие правки в приложение»

Это описание первого набора изменений. Актуальное продолжение: [«Правки 2»](revision2.md).

Реализованы в ветке `design/experiments`, 23 октября 2026 года. Изменения из документа использованы как требования к интерфейсу; медицинская база правил и внешние каналы связи не подменяются демонстрацией.

## Пациент

| Запрос | Что изменилось |
|---|---|
| Дерево по касанию | Нажатие на дерево или «Моё дерево» на главной открывает «Движение». Там каждое касание добавляет цветок, независимо от заданий; сохраняется до 120 дополнительных цветов. Нажатия не создают записи о самочувствии или выполненных занятиях. |
| Движение | Дерево, затем календарь активности, затем четыре упражнения с выбором даты. Занятие можно запланировать, убрать или отметить выполненным за сегодня/прошедший день. Повторное подтверждение не создаёт дубль. Иконка — бегущий человек. |
| Паузы и практики | Перенесены в «Помощь → Дыхание». Отдельное упражнение «Размяться без спешки» удалено из доступного списка; прежние сохранённые отметки не удаляются. |
| Сейчас | Вопрос «Как вы сейчас?» и четыре состояния. Рекомендованные действия раскрываются прямо под выбранным состоянием, без перехода на другую страницу. Названия ВОЛНА/СТОП/ПАУЗА убраны. |
| Дыхание | Список из семи раскрывающихся упражнений: дыхание 4–2–6, заземление, спокойная пауза и четыре упражнения движения. Перед началом — плавное появление вопроса о готовности и кнопка подтверждения. В системном режиме уменьшения движения анимации отключены. |
| Заземление | Пять этапов: 5 видимых вещей, 4 поверхности для касания, 3 звука, 2 запаха, 1 вкус. У этапов есть пояснения и последовательное выделение. |
| Игры | Остались пузырьки; шарик и поиск пары удалены из интерфейса. |
| План | Один заголовок «План безопасности» и последовательность из шести пронумерованных пунктов; соглашение сохранено ниже. |
| SOS | Одна видимая тревожная кнопка на каждом экране: компактная постоянная кнопка либо большая красная в «Помощь → SOS». Отправка при удержании 1,5 секунды; короткое удержание ничего не отправляет. Для клавиатуры сохранено подтверждение. |
| Содержимое SOS | Сначала кнопка, затем доверенный человек, затем контакты с категориями. Текст запроса: «Мне сейчас нужна поддержка. Пожалуйста, свяжитесь со мной». Запрос появляется у врача и у связанного близкого, если разрешено пациентом. |
| Счётчик | Кнопка «Начать отсчёт», затем живой секундомер с днями, часами, минутами и секундами. Начало хранится на сервере и сохраняется после перезагрузки; неверные часы браузера не мешают запуску. Доступен только пациенту. |
| Главная и меню | Круговые действия совпадают с шестью основными и двумя дополнительными пунктами бокового меню. На остальных страницах есть кнопка «Назад». |
| Вложенные разделы | Опросы и препараты открываются во вкладках дневника, карта — во вкладке сообщений, согласия — в настройках, дерево — в движении. Подвкладки, состояния и упражнения не создают отдельных URL или записей в истории браузера. |
| Формулировки | «Сделать перерыв», «Лучшее средство от тревоги», «Расслабиться», «Без спешки». |

Запрос SOS сохраняется в приложении и создаёт уведомления. Отправка SMS, автоматический звонок, сообщение в Telegram и вызов экстренной службы этим изменением не подключались. Контакт в форме сам по себе не создаёт учётную запись близкого. Нет сети — запрос не отправляется и не ставится в скрытую очередь.

Цветы и календарь требуют связи с сервером для сохранения. Движение дерева на уже открытом экране продолжает работать без сети. Прежняя зашифрованная офлайн-копия назначений и записей остаётся доступна по PIN.

## Врач и близкий

Главная врача содержит календарь по месяцам: точки обозначают консультации, выбор даты показывает записи на этот день, нажатие на пациента открывает его карточку. Учитываются сохранённые консультации, отменённые исключены. Время — московское.

Профессии убраны из списка и заголовков карточек пациента. Период «Наблюдается с…» берётся из самой ранней сохранённой записи о регистрации, посещении или самоотчёте. Если дата неизвестна, это обозначено; дата не выдумывается.

Калькулятор позволяет выбрать закреплённого пациента либо задать характеристики вручную, выбрать АВИАНДР как пример названия или вымышленные варианты, указать факторы и второй вариант. Результат показывает учебные ограничения и причины. Учитывается сохранённая учебная несовместимость выбранного пациента; смена параметров сбрасывает старый результат. Все правила придуманы для демонстрации: официальная инструкция АВИАНДРа не подключена, заключений о безопасности реального приёма нет.

В кабинете близкого пункт «Куда звонить» переименован в «Полезные контакты».

## Как опробовать

На Render откройте свой Web Service. В настройках ветки должна быть указана `design/experiments`. При включённом автоматическом развёртывании новый коммит запустит обновление; иначе выберите **Manual Deploy → Deploy latest commit**. Дождитесь статуса **Live**, затем обновите страницу приложения при доступном сервере. Для установленной PWA при необходимости закройте и откройте её снова. Новая оболочка: `compass-shell-v7`.

Существующая база не очищается: новые таблицы создаются автоматически при запуске. На Render она должна оставаться на постоянном диске (`COMPASS_DB=/var/data/compass.db`).

Локально в папке проекта:

```sh
git fetch origin
git switch design/experiments
git pull --ff-only origin design/experiments
```

Далее запустите приложение по README. Пациент `patient-a`, врач `doctor`, близкий `relative`; пароль — `compass-demo`. Для одновременного показа используйте отдельные браузеры/профили или устройства.

Сценарий: пациент открывает дерево → добавляет цветы → планирует и отмечает прогулку → раскрывает упражнение в «Помощи» → запускает секундомер → удерживает SOS → врач и близкий видят запрос. Затем врач выбирает дату в календаре и проверяет несколько сценариев в калькуляторе.

## Проверки

`python -m unittest discover -s tests -v`: 62 серверных теста, в том числе права доступа, повторная отправка, хранение цветов, календарь и приватность секундомера.

`python tests/browser_revisions.py`: все новые сценарии, три роли, четыре размера экрана, рост числа видимых цветов, сохранение после перезагрузки, отсутствие переходов для подвкладок, секундомер, удержание/отмена SOS, календарь врача, калькулятор и «Назад».

Также проверены `browser_smoke.py`, `browser_workflows.py`, `browser_psicompas.py`, `browser_sections.py` и `browser_responsive.py`. Проверки используют временные синтетические базы; это не проверка доставки push на физический телефон или запуска внешнего ИИ.
