# Дерево и цветы

Ветка `design/experiments`.

На главной пациента дерево теперь только открывает страницу «Моё дерево»: нажатие не добавляет цветы и не запускает покачивание. На отдельной странице дерево доступно для нажатия мышью, пальцем и клавишами Enter/пробел.

Там нажатие покачивает дерево и добавляет только розовые цветки радиусом 3–4,5 единицы SVG. Цветки за сохранённые действия имеют радиус 8–10 единиц: жёлтые за приём, синие за завершённую консультацию, сиреневые за дневник, зелёные за упражнение. Старые розовые цветки тоже отображаются уменьшенными; записи базы сохраняются. При уменьшении анимации в настройках устройства покачивание отключается, добавление цветка работает.

Проверены переход без добавления цветков, анимация на странице дерева, сохранение и разница размеров, компоновка на пяти ширинах 320–1440 px. Дополнительно проверены прежняя анимация дерева и серверные сценарии активности.

На Render: **Manual Deploy → Deploy latest commit**, дождаться **Live**, обновить страницу. Кеш PWA — `compass-shell-v23`.
