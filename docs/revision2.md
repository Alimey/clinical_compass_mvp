# «Правки 2» — обновление кабинета пациента

Реализовано 23 октября 2026 года в ветке `design/experiments`. Это продолжение [первого набора правок](current-changes.md). Требования и четыре изображения из DOCX использованы как описание интерфейса; числа и названия из примеров не подставляются вместо текущих данных.

## Что изменилось

| Раздел | Результат |
|---|---|
| Главная | Кнопка паузы дерева убрана. Касание дерева добавляет два розовых кружка в месте касания, без перехода и перезапуска анимации. «Моё дерево» отдельно открывает «Движение». |
| Дневник | Календарь, сохранённые записи выбранного дня и форма новой записи находятся на одной странице. Переключателей «Самоотчёт / Календарь / История» и вводного заголовка нет. Смена даты не стирает заполненную форму. Новая запись относится к текущему дню. |
| Графики | Последовательно: доступ специалиста, ИИ-расшифровка, тревога/качество сна/энергия на одном графике, компактный календарь жалоб за 14 дней, графики сохранённых баллов шкал. Пропуски сна/энергии не заменяются нулями. |
| Препараты | Только таблица за последние 14 дней: дата, назначения и их времена, другие ранее записанные варианты, жалобы. Отметки времён стоят рядом. Кнопка «✓ / × / —» позволяет отметить приём/пропуск; будущие времена недоступны. «—» означает отсутствие отметки. Назначения остаются синтетическими, реальные дозировки с картинки не добавлены. |
| Записи | Остались питание и личные заметки. Дневник мыслей убран из этой вкладки; он по-прежнему доступен в «Знаниях». |
| Движение | Простое анимированное дерево с касаниями. Ни счётчика цветов, ни инструкций-заданий у дерева нет. Ниже — зелёная шкала «выполнено часов / запланировано часов» за текущую неделю с понедельника, затем календарь и список упражнений. Часы считаются по самоотметкам, включая выполненные физические упражнения вне плана, без двойного счёта запланированных занятий. |
| Школа | Убраны лишние заголовки и блок «Понятно о повседневном». Пять тем раскрывают заглушки для будущих видео. Заглушки не выдают себя за записанное видео и не отмечаются просмотренными автоматически. |
| Сейчас | Кризисные состояния раскрываются на текущей странице. Показывается один шаг, переход — кнопкой «Дальше», после последнего можно начать снова. Ссылка 112 остаётся сразу доступна в соответствующем состоянии. |
| Дыхание | Круг растёт на вдохе 4 секунды, остаётся большим на паузе 2 секунды и уменьшается на выдохе 6 секунд. После пяти циклов упражнение завершено. В заземлении виден один из пяти этапов; «Далее» переключает его. «Спокойная пауза» удалена. |
| Завершение упражнений | Дыхание, заземление и четыре физических упражнения автоматически сохраняют выполнение, обновляют общий счётчик и показывают поздравление. Повтор таймера или ответ сети не создаёт дубль. При ошибке сети показано, что отметка не сохранена, и доступен повтор сохранения. |
| План / SOS | На компьютере карточки идут вертикально, во всю доступную ширину. Пункты плана безопасности — один под другим; тревожная кнопка, доверенный человек и справочник контактов также идут последовательно. |
| Врач | Пункт «Сообщения» и круг на главной переименованы в «Врач». Во вкладках только чат, письма и помощник; «Моя карта» удалена. Лишних заголовков перед переключателем нет. |
| Консультации | «Мои встречи» переименованы в «Консультации», включая круг на главной. Пункт находится вместе с основными разделами; разделительная линия отделяет только настройки. |
| Настройки | Иконка-шестерёнка. Переключатель находится над содержимым, а не сбоку. В основной вкладке только push и установка PWA. «Сценарий» удалён. Согласия и информация о проекте остаются отдельными подвкладками. |

Зашифрованное сохранение назначений для чтения без сети перенесено в **Настройки → Мои согласия → Назначения и записи без интернета**. Существующие копии не очищаются этим обновлением.

Дерево продолжает двигаться на открытой странице без сети, но сохранение цветов требует сервера. Координаты касаний хранятся в базе; отображаются последние 120 цветков. В системном режиме уменьшения движения анимации отключаются. Нажатия на дерево не создают медицинские записи или выполненные упражнения.

## ИИ-расшифровка графиков

При открытии «Графиков» приложение автоматически запрашивает внешнюю модель через уже существующий OpenAI-совместимый адаптер. Модель получает сводку синтетических данных: рассчитанные средние за недели, дни жалоб и срочных отметок, количество отметок приёма и сохранённые баллы шкал. Имя, телефон, переписка и свободный текст дневника в этот запрос не включаются.

Ответ кэшируется в базе для текущего набора данных. Новые записи, отметки приёма, шкалы или смена отчётного периода обновляют расшифровку. В браузере текст выводится безопасно, без исполнения HTML. Сервис не получает разрешение ставить диагнозы, менять план или придумывать значения. Ответ модели остаётся наблюдением для обсуждения с врачом, а не медицинским заключением.

Если на Render ещё не подключён ИИ, в **Environment** нужны три переменные:

```text
COMPASS_AI_BASE_URL=https://адрес-провайдера/v1
COMPASS_AI_MODEL=доступная-вам-модель
COMPASS_AI_API_KEY=ваш-секретный-ключ
```

Адрес берётся из документации провайдера и указывается без `/chat/completions`. Ключ вводится только в настройках сервера; не отправляйте его в чат и не добавляйте в Git. После изменения настроек перезапустите развёртывание.

Без настроенной модели графики работают, а вместо расшифровки показано «ИИ ещё не подключён». При пустой истории показана нехватка данных; при ошибке провайдера — недоступность. Готовый текст из DOCX не используется как ответ ИИ. Живой запрос к вашему провайдеру без ваших настроек не проверен; контракт и кэш проверены изолированными тестами.

## Обновление и показ

В Render проверьте ветку `design/experiments`. При отключённом автоматическом обновлении: **Manual Deploy → Deploy latest commit**, дождаться **Live**. Обновите страницу при доступном сервере; установленную PWA при необходимости закройте и откройте. Версия оболочки — `compass-shell-v8`. База не очищается: дополнительные таблицы создаются при запуске. Для сохранения данных между развёртываниями требуется прежний постоянный диск.

Для показа: пациент нажимает на дерево на главной → «Моё дерево» → добавляет занятие в календарь → открывает дневник и графики → таблицу препаратов → заглушку урока → проходит заземление и видит обновлённый счётчик → открывает «План» и настройки на компьютере.

Проверки: 69 серверных тестов; браузерные сценарии `browser_revision2.py`, `browser_revisions.py`, `browser_responsive.py`, `browser_sections.py`, `browser_workflows.py`, `browser_psicompas.py`, `browser_smoke.py`. Новая проверка покрывает 5 размеров экрана, общая адаптивная проверка — 8, от 320 до 1920 px. Проверены задержка сохранения цветов, сохранность черновика при смене даты, кэш ИИ, однократное автозавершение, таблица отметок, расположение карточек, роли, прежние формы и офлайн-копия.
