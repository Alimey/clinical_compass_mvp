# Сценарий демонстрации

1. **0:00–0:35:** вход, лента консультаций, карточка с основными данными, посещением и анализом.
2. **0:35–1:15:** назначить короткий опрос; во втором окне пациент отвечает и отмечает таблетницу.
3. **1:15–1:50:** специалист видит ответы, обсуждает их с пациентом в чате; показать непрочитанное/прочтение.
4. **1:50–2:30:** при заранее подключённом API запросить короткую ИИ-сводку; проверить и обсудить, не меняя план автоматически. Без API этот пункт нельзя выдавать за работающий ИИ.
5. **2:30–3:00:** показать запись на приём или регистрацию по приглашению; офлайн-копию оставить для вопросов.

Четыре технических сценария для подготовки: первичная регистрация, регулярное наблюдение, сигнал безопасности с проверкой специалистом, офлайн-доступ. Медицина и протоколы эскалации требуют отдельной проверки вашей медкомандой. При непосредственной опасности нужна экстренная помощь, а не ожидание ответа в приложении.
