# Результат проверки противопоказаний

Ветка `design/experiments`.

В калькуляторе врача явное ограничение теперь выводит красный результат **«Назначать нельзя»**, метку **«Противопоказание»** и список причин. Предупреждения не понижают приоритет запрета и показываются ниже отдельно.

Поля разделены на две группы:

- **Противопоказания:** аллергия на выбранный препарат; отдельная отметка врача «Противопоказание к выбранному препарату подтверждено по инструкции».
- **Факторы для дополнительной проверки:** беременность/лактация, эпилепсия, сердечно-сосудистые заболевания и диабет. Существующие поля возраста, функции почек и печени и правила демонстрационных сочетаний сохранены.

Эта правка не добавляет неподтверждённых противопоказаний реального препарата. Отметка по инструкции — сведения, которые подтверждает врач. Прежние условные правила калькулятора остаются демонстрационными; реальный лекарственный справочник требует отдельной верификации.

Если изменены параметры, результат сбрасывается и требуется повторная проверка. При смене препарата отметки аллергии и подтверждённого противопоказания сбрасываются: их нужно проверить заново для нового препарата. В результате без отмеченных ограничений не выводится разрешение назначать препарат. Калькулятор не создаёт и не меняет назначения.

Проверяются: аллергия; подтверждённое противопоказание; сочетание запрета с предупреждением; сброс устаревшего результата; самостоятельное предупреждение; ограничение из карточки; условное несовместимое сочетание; отсутствие изменений терапии при расчёте.
