# «Правки 8» — опросники, упражнения, игры и дерево

Ветка `design/experiments`.

Актуализация по «Проектику»: MMPI и обе методики Бека перенесены в блок «Проводится на приёме по лицензии», онлайн-вопросы убраны. Подробнее — [текстовые изменения](project-copy.md).

Врач назначает формы через «Пациенты → Карточка пациента → Шкалы» или вкладку «Опросы»: выбирает форму и срок, при необходимости отменяет задание. Пациент видит только назначенные формы в «Дневник → Шкалы». Самостоятельного запуска из каталога больше нет.

Добавлены формы MMPI, Леонгарда–Шмишека, безнадёжности Бека, депрессии Бека, ситуативной и личностной тревожности Спилбергера, HCL-33, MDQ, самооценки Дембо–Рубинштейн и COPE.

**Это короткие учебные формы с оригинальными демонстрационными вопросами, а не полные бланки указанных методик.** В каждой по шесть вопросов. Ответы сохраняются в SQLite и доступны ведущему специалисту; клинические ключи, диагностические баллы и заключения для этих форм не применяются. Для точных версий потребуются согласованные бланки, переводы, условия использования и ключи. Прежние учебные GAD-7, PHQ-9 и HAM-A сохранены.

Два упражнения реализованы отдельно:

- **Таблицы Шульте:** случайная таблица 5×5, числа от 1 до 25, проверка порядка, время от первого правильного нажатия и сохранение результата.
- **Вычитание по 7 из 100:** 13 последовательных ответов, проверка правильности, число верных ответов и сохранение для специалиста.

В «Знания → Школа» переименованы пять видео по списку из DOCX. В «Как помочь» переименованы три видео для близкого. Сами видео остаются местами для будущего контента; видеозаписи в документе не приложены.

## Игры

В «Помощь → Игры» появился **«Лабиринт ХимРАР»**: персонаж собирает пилюли в сиреневом лабиринте, встречает препятствия и избегает розового преследователя. Доступны стрелки клавиатуры, экранные кнопки и касание соседней клетки. После сбора всех пилюль — победа; при столкновении можно начать заново. Преследователь делает ход после каждых трёх шагов игрока. Игра пошаговая, без фонового движения и связи с назначениями.

В «Варенье» ягоды в миске лопаются при касании: частицы расходятся, затем на том же месте вырастает новая ягода. Повторное касание работает. Наполнение банок и перенос на полку сохранены.

## Счётчик и дерево

У счётчика появилось поле **«Что отсчитываем?»**. Название сохраняется для текущего пациента, отображается на главной, используется в том же счётчике в «Помощи» и не передаётся врачу с личными настройками. Смена названия не сбрасывает время.

Нажатие на дерево на главной только открывает отдельную страницу дерева. Уже там нажатие покачивает дерево и добавляет маленький розовый цветок. Цветы за действия крупнее. Легенда:

| Цвет | Событие |
|---|---|
| Жёлтый | Приём лекарства отмечен как выполненный |
| Синий | Врач завершил консультацию |
| Сиреневый | Сохранена запись в дневнике |
| Зелёный | Завершено упражнение |
| Розовый | Касание дерева |

Цветные цветы вычисляются из сохранённых серверных записей. Обновление страницы не создаёт повторных наград; позиции стабильны. Показываются последние 30 событий каждого вида. Цветы за действия видны на главной и на странице дерева; на отдельной странице убраны декоративные розовые цветы, чтобы они не смешивались с отметками действий. Цветы не оценивают состояние или успешность лечения.
