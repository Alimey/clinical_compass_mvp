Установка на телефон

Android: откройте HTTPS-адрес в Chrome и выберите «Установить приложение» в меню. iPhone: откройте адрес в Safari → «Поделиться» → «На экран Домой».

Нужен интернет

Без сети доступна только оболочка приложения. Самоотчёты не сохраняются офлайн и не отправляются автоматически. Данные не кэшируются для офлайн-просмотра.

Ограничения демо

Нет авторизации, push-уведомлений, клинического триажа и защиты, необходимой для медицинских персональных данных. Вопросы не являются валидированной шкалой. Используйте только вымышленные сведения в контролируемой среде.

При непосредственной опасности нужна экстренная помощь. Не ждите ответа в приложении.
