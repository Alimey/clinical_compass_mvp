# ПсиКомпас

PWA для сопровождения пациента между консультациями психолога или психотерапевта. Приложение объединяет дневник самочувствия, опросы, назначения, расписание и общение со специалистом.

Демонстрационный прототип использует вымышленные данные и учебные сценарии.

## Пользователи

| Роль | Назначение кабинета |
| --- | --- |
| Специалист | Пациенты, динамика состояния, назначения, опросы и консультации |
| Пациент | Дневник, задания, таблетница, запись на приём и чат |
| Близкий | Разрешённые пациентом сигналы и материалы по поддержке |

## Возможности

- Регистрация по ролям и приглашениям, разграничение доступа и согласия пациента.
- Карточки пациентов, дневник, графики, опросы и история посещений.
- Расписание консультаций, назначения и отметки приёма лекарств.
- Чат, уведомления, напоминания и запрос поддержки SOS.
- Материалы самопомощи, упражнения, игры и дерево активности.
- Установка PWA, адаптивный интерфейс и просмотр сохранённой офлайн-копии под PIN.
- Подключаемые интеграции с внешним ИИ, Telegram и Web Push.

## Технологии

**Сервер:** Python, Flask, SQLite. **Интерфейс:** HTML, CSS, JavaScript, Service Worker. **Запуск:** Gunicorn на Linux, Waitress для локальных замеров Windows, Docker.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `app.py` | Создание Flask-приложения, авторизация и основные API |
| `compass/` | Серверные модули: данные, сопровождение, интеграции и фоновые задачи |
| `static/` | Интерфейс, стили, изображения и PWA |
| `tests/` | Серверные и браузерные проверки |
| `tests/measurements/` | Нагрузочные и браузерные замеры, сборка отчётов |
| `docs/` | Инструкции, описание функций и результаты испытаний |
| `run-local-tests.cmd` | Запуск локальных замеров на Windows |
| `Dockerfile`, `gunicorn.conf.py` | Конфигурация запуска сервера |
| `requirements.txt`, `requirements.lock`, `.env.example` | Зависимости и образец настроек |
