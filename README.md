# Клинический компас · мобильное демо

Устанавливаемое веб-приложение **PWA для Android и iPhone**. Сервер на Flask и SQLite, мобильный интерфейс на HTML/CSS/JavaScript без сборки Node.js. После установки запускается с иконки на главном экране. APK и публикация в App Store для этой версии не требуются.

## Функционал

- **Пациент:** настроение и тревога от 0 до 10, соблюдение рекомендаций, самочувствие, комментарий и отметка опасений за безопасность.
- **История:** карточки всех самоотчётов и график последних 14 записей с точными значениями ниже.
- **Врач:** выбор демо-пациента, последние оценки, самоотчёты, новые сигналы и отметка их просмотра.
- **Решения врача:** ручной выбор действия, обоснование, отдельная история сохранённых решений.
- **Мобильный интерфейс:** нижняя навигация, крупные элементы управления, поддержка узких экранов и установка на главный экран.
- **Без сети:** открывается оболочка. Данные пациентов не кэшируются, запись и автоматическая фоновая отправка недоступны. Неотправленный текст остаётся только в открытой форме; после закрытия или перезагрузки он пропадёт.

Переключение «Пациент / Врач» — демонстрация, **не авторизация**. Данные доступны всем, кто имеет доступ к серверу. Используйте только вымышленные сведения в контролируемой среде.

## Запуск на компьютере

Нужен Python 3.10+ (проверено на 3.12).

```bash
git clone https://github.com/Alimey/clinical_compass_mvp.git
cd clinical_compass_mvp
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe app.py
```

macOS / Linux:

```bash
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python app.py
```

Если репозиторий уже скачан, вместо повторного клонирования выполните `git pull --ff-only` в его папке. Откройте `http://127.0.0.1:8000` на компьютере. Остановка: Ctrl+C. Пакет gunicorn используется только для Linux-развёртывания; на Windows при установке пропускается автоматически.

## Опробовать на телефоне в одной Wi-Fi сети

Запустите сервер с прослушиванием локальной сети.

Windows PowerShell:

```powershell
$env:COMPASS_HOST = "0.0.0.0"
.\.venv\Scripts\python.exe app.py
```

macOS / Linux:

```bash
COMPASS_HOST=0.0.0.0 .venv/bin/python app.py
```

Узнайте локальный IPv4 компьютера (`ipconfig` на Windows, настройки Wi-Fi на macOS/Linux). На телефоне откройте `http://IP-КОМПЬЮТЕРА:8000`, например `http://192.168.1.10:8000`. При необходимости разрешите входящие подключения к TCP 8000 для частной сети в брандмауэре. Компьютер должен оставаться включённым, сервер — запущенным.

По локальному HTTP можно проверить интерфейс и формы. **Полноценная установка PWA и service worker на телефоне требуют HTTPS**; исключение localhost относится к самому устройству, а не соседнему компьютеру.

## Установить PWA на Android и iPhone

Разместите сервер на Python-хостинге с HTTPS и постоянным диском. Для Linux команда запуска:

```bash
gunicorn --bind 0.0.0.0:8000 --workers 1 'app:create_app()'
```

Подключите HTTPS reverse proxy, передающий исходный `Host`. Внешний порт приложения выбирается параметром `--bind`; `PORT` используется при запуске `python app.py`. Сохраните SQLite на постоянном диске, например задав `COMPASS_DB=/data/compass.db`. Файловая система без постоянного диска теряет записи после пересоздания сервера. В репозитории также есть Dockerfile; контейнер использует `/data/compass.db`, смонтируйте volume на `/data`.

- **Android:** откройте HTTPS-адрес в Chrome → меню → «Установить приложение» / «Добавить на главный экран». Кнопка «Установить» также появляется в приложении, когда браузер разрешает установку.
- **iPhone:** откройте HTTPS-адрес в Safari → «Поделиться» → «На экран Домой» → «Добавить».

Доступного публичного сервера этот репозиторий сам по себе не создаёт. GitHub Pages не запускает Python API. Приложение не публиковалось в магазинах. Реальная установка на физических Android/iPhone требует отдельной проверки после HTTPS-развёртывания.

## Демонстрационный сценарий

1. В режиме «Я пациент» выберите пациента А, заполните и сохраните самоотчёт.
2. Откройте «История»: проверьте карточку и график.
3. Отправьте ещё один отчёт с отметкой опасений за безопасность: появится сообщение о необходимости экстренной помощи при непосредственной опасности.
4. Перейдите в «Я врач»: увидите отчёты и новый сигнал. Отметьте сигнал просмотренным.
5. Запишите решение врача с вымышленным обоснованием. Оно появится в истории решений.
6. Выберите пациента Б: у него отдельные записи.

Это не система уведомлений: врачу нужно открыть или обновить обзор; push, SMS и гарантированного мониторинга нет.

## Данные и совместимость

По умолчанию создаётся новая база `instance/compass.db`, исключённая из Git. Путь задаётся переменной `COMPASS_DB`. Время сохраняется в UTC, интерфейс показывает часовой пояс устройства.

Исходная `demo.db` сохранена без изменений. Схема совместима с прежним Streamlit-прототипом. Чтобы продолжить демонстрацию со старыми данными, **остановите сервер**, создайте папку `instance` и скопируйте `demo.db` в `instance/compass.db`, если целевой файл ещё не существует. Не перезаписывайте существующую рабочую базу; сначала сделайте резервную копию.

Для сброса демо остановите сервер и удалите только рабочую `instance/compass.db` (либо свою базу `COMPASS_DB`), предварительно сохранив нужные данные.

## Проверки

```bash
.venv/bin/python -m unittest discover -s tests -v
node --check static/app.js
node --check static/sw.js
```

На Windows замените `.venv/bin/python` на `.\.venv\Scripts\python.exe`. Node.js нужен только для необязательной проверки синтаксиса JavaScript, не для работы приложения.

Дополнительная браузерная проверка в изолированной временной базе:

```bash
.venv/bin/python -m pip install playwright
.venv/bin/python -m playwright install chromium
.venv/bin/python tests/browser_smoke.py
```

Можно использовать системный Chromium; при необходимости задайте `CHROMIUM_PATH`. Проверяется полный сценарий, разделение пациентов, экранирование HTML, отсутствие API в офлайн-кэше, работа оболочки без сети и экраны шириной 320/390/430/1280 px. Проверка использует Chromium; она не заменяет проверку Safari и физических устройств. Скриншоты на Linux записываются в `/tmp/compass-artifacts`.

## Что изменилось

Streamlit и pandas заменены Flask API и адаптивным PWA-интерфейсом. Добавлены manifest, иконки, service worker, серверная валидация, обработка сетевых ошибок, тесты API и браузерного сценария. SQLite и основные пользовательские сценарии сохранены. Рабочая база отделена от Git; зависимости зафиксированы в `requirements.lock`.
