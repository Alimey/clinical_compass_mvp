# Клинический компас — стартовый прототип

Учебное Streamlit-приложение с двумя режимами: «Врач» и «Пациент».

## Запуск

Установите Python 3.10+ и выполните в папке проекта:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

После запуска браузер откроет http://localhost:8501.

## Демонстрационный сценарий

1. Выберите «Пациент» и отправьте самоотчёт.
2. Переключитесь на «Врач» и откройте того же пациента: самоотчёт отображается в карточке.
3. Вернитесь к пациенту, установите флажок опасений за безопасность, отправьте форму.
4. Переключитесь к врачу: появится сигнал, который можно пометить просмотренным.
5. Врач может зафиксировать решение, которое сохраняется отдельно.

Данные остаются в локальном файле `demo.db` (SQLite). Чтобы начать с пустой базы, закройте приложение и удалите этот файл.
